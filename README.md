# java-estudos

Repositório com meus estudos de Java, reunindo exemplos e exercícios de cada tópico da disciplina de Programação II (UFRN) e do meu cronograma pessoal de estudos.

## Objetivo

Praticar e fixar os fundamentos de Java e orientação a objetos, estudando principalmente pela documentação oficial, como base para minha carreira em desenvolvimento backend.

## Conteúdo

| Tópico | Descrição |
|---|---|
| Classes, objetos e encapsulamento | Modificadores de acesso, getters/setters |
| Herança e polimorfismo | `extends`, sobrescrita, `super` |
| Abstração | Classes abstratas, interfaces e enums |
| Exceptions | `try/catch/finally`, exceções customizadas |
| Collections e Generics | `List`, `Set`, `Map`, tipos genéricos |
| Lambdas, Streams e Optional | `stream()`, operações intermediárias e terminais, `Collectors`, `Optional` |

## Como executar

**Pré-requisitos:** JDK 17 ou superior (ajuste para a versão que você usa) e, opcionalmente, o IntelliJ IDEA.

**Pelo IntelliJ:**
1. Clone o repositório:
```bash
   git clone https://github.com/Theu13/java-estudos.git
```
2. Abra a pasta no IntelliJ IDEA.
3. Execute a classe `Main` do tópico desejado.

**Pelo terminal:**
```bash
cd java-estudos/src
javac NomeDoPacote/Main.java
java NomeDoPacote.Main
```
